Welcome to Full Stack Fundamentals Course

Learn the core concepts of full-stack development, including frontend and backend technologies!

Introduction to Full Stack Development

Full Stack Development involves both frontend and backend development. In this course, we'll cover:

  • Frontend Basics: HTML, CSS, JavaScript
  • Backend Basics: Node.js, Express.js, Databases
  • Connecting Frontend and Backend
  • Building Full-Stack Applications

Frontend Fundamentals

HTML: The Structure of the Web

HTML is used to create the structure of web pages. You'll learn how to build the basic skeleton of any website.

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
</html>

CSS: Styling the Web

CSS is used to style the HTML structure. You'll learn how to position and color elements to create beautiful web pages.

h1 {
    color: blue;
    text-align: center;
}

JavaScript: Making the Web Interactive

JavaScript adds functionality to your website. You'll learn how to interact with the DOM and handle user input.

document.getElementById("myButton").onclick = function() {
    alert("Button Clicked!");
};

Backend Fundamentals

Node.js: JavaScript on the Server

Node.js allows you to run JavaScript on the server. You'll learn how to set up a basic server with Node.js.

const http = require('http');

const server = http.createServer((req, res) => {
    res.write('Hello from the server!');
    res.end();
});

server.listen(3000, () => {
    console.log('Server is running on port 3000');
});

Express.js: Simplifying Server-Side Development

Express.js is a framework for Node.js that makes it easier to handle routes, requests, and responses.

const express = require('express');
const app = express();

app.get('/', (req, res) => {
    res.send('Hello World!');
});

app.listen(3000, () => {
    console.log('Server is running on port 3000');
});

Databases: Storing Data

Learn how to store and retrieve data from a database. We'll cover SQL (MySQL) and NoSQL (MongoDB) databases.

Example with MongoDB

const mongoose = require('mongoose');

mongoose.connect('mongodb://localhost:27017/mydb', { useNewUrlParser: true, useUnifiedTopology: true })
    .then(() => console.log('Connected to MongoDB'))
    .catch(err => console.error('Could not connect to MongoDB:', err));

Connecting Frontend and Backend

Now that you have a basic understanding of frontend and backend development, you'll learn how to connect them:

  • Creating APIs with Express.js
  • Sending and receiving data with AJAX and Fetch API
  • Handling form submissions

Example of sending data to backend using Fetch:

fetch('http://localhost:3000/submit', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({ name: 'John', age: 30 })
})
.then(response => response.json())
.then(data => console.log(data));

Building a Full-Stack Application

Now, it's time to combine everything you've learned and build a full-stack application. Here's a brief outline:

  • Frontend: Create the user interface using HTML, CSS, and JavaScript.
  • Backend: Set up a server using Node.js and Express.js to handle requests.
  • Database: Store and retrieve data from a database like MongoDB.
  • Connect: Use AJAX/Fetch API to communicate between frontend and backend.

By the end of this project, you'll have a fully functional web application!

Conclusion

Congratulations! You've learned the fundamentals of full-stack development. Keep building and experimenting with real projects, and you'll be ready for more advanced topics like authentication, deployment, and working with frameworks like React and Angular.

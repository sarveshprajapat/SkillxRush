Introduction to Basic Syntax

Understanding the basic syntax is crucial for learning how to write code effectively. In this section, we'll go over how syntax works in programming, and how it varies between different programming languages. This includes rules for naming variables, using operators, and writing statements.

Variables

Variables are used to store data that can be used and manipulated in a program. Here's an example of how to declare variables in different programming languages:

  • Python: my_variable = 10
  • JavaScript: let myVariable = 10;
  • C++: int myVariable = 10;

Data Types

Data types define what kind of data a variable can hold. Common data types include:

  • Integer: Whole numbers (e.g., 10, 42)
  • Float: Decimal numbers (e.g., 3.14, 99.9)
  • String: Text data (e.g., "Hello, World!")
  • Boolean: True or False values

Operators

Operators allow you to perform operations on variables and values. Some common operators are:

  • Arithmetic Operators: +, -, *, /, %
  • Comparison Operators: ==, !=, >, <, >=, <=
  • Logical Operators: && (AND), || (OR), ! (NOT)

Control Structures

Control structures dictate the flow of a program. The most common control structures are:

  • If Statements: Execute a block of code based on a condition.
  • Loops: Repeatedly execute a block of code (for, while).
  • Switch Statements: Choose between multiple options based on a variable.

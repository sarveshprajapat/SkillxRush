Course Overview

This course is designed for beginners who want to learn the basics of programming. It will cover key concepts such as variables, data types, loops, and functions. By the end of this course, you will have the foundational skills to write simple programs and solve problems using code.

Syllabus

  • Week 1: Introduction to Programming and Setting Up Development Environment
  • Week 2: Variables, Data Types, and Operators
  • Week 3: Conditional Statements (If/Else)
  • Week 4: Loops (For, While)
  • Week 5: Functions and Modular Programming
  • Week 6: Introduction to Data Structures (Arrays/Lists)
  • Week 7: Debugging and Error Handling
  • Week 8: Final Project and Review

Assignments

Throughout the course, you will complete the following assignments to solidify your understanding:

  1. Assignment 1: Create a simple calculator using basic arithmetic operations.
  2. Assignment 2: Build a program that checks if a number is prime.
  3. Assignment 3: Develop a program that finds the largest number in a list of integers.
  4. Assignment 4: Final Project: Create a program that solves a real-world problem.
